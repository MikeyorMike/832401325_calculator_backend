一键启动前后端服务

用于本地演示与截图

操作步骤

  1. 双击本目录下的 启动.bat
  2. 会弹出两个黑色命令行窗口，分别是后端和前端服务，不要关闭它们
  3. 等后端窗口出现 Uvicorn running on http://127.0.0.1:8000
  4. 浏览器自动打开前端页面；若没有自动打开，手动访问 http://127.0.0.1:5500
  5. 页面顶部显示绿点「后端已连接」即成功

常见问题

提示「python 不是内部或外部命令」
未安装 Python 或未加入 PATH。安装 Python 3.11+ 时勾选「Add Python to PATH」
提示端口被占用
8000 或 5500 端口已被其他程序占用。关闭占用程序， 或修改 启动.bat 里的端口号
页面提示「后端未连接」
后端窗口是否还在运行？是否报错？先访问 健康检查 确认后端是否正常
首次运行需要安装依赖
启动.bat 会自动检测并安装依赖，首次运行请耐心等待 1~2 分钟
