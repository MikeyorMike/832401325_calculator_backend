## 0. 拍摄前的准备

### 0.1 环境检查

```powershell
# 1. 启动后端
cd 832401325_calculator_backend
.venv\Scripts\Activate.ps1
python run.py

# 2. 另开一个终端启动前端
cd 832401325_calculator_frontend\src
python -m http.server 5500
```

浏览器打开 <http://127.0.0.1:5500>，确认顶部显示绿点「后端已连接」。

> **建议用本地环境截图**，而不是线上 —— 线上 Render 冷启动时截图会出现
> 「计算中…」的等待画面，不好看。本地截图响应快，画面干净。
> 但**至少要有 1~2 张线上地址的截图**，证明确实部署成功了。

### 0.2 让截图更可信的三个技巧

1. **截图里要能看见浏览器地址栏**。用 `Win + Shift + S` 只框选网页内容区，
   会看不出访问的是哪个地址。建议按 `F11` 全屏后整屏截图（`PrtSc` 或
   `Win + PrtSc` 自动保存到 `图片\屏幕截图`），这样地址栏、时间都在，最有说服力。
2. **把系统时间露出来**。Windows 任务栏右下角的时间能证明截图是「刚刚」拍的，
   而不是从别处找来的图。
3. **关键流程录 GIF**。GIF 比静态图更能证明功能真实可用。
   推荐 [ShareX](https://getsharex.com/)（免费，可录屏转 GIF 和视频）。

### 0.3 文件命名建议

```
screenshots/
├── 01-主界面.png
├── 02-加法.png
├── 03-减法.png
├── ...
├── 13-历史持久化.gif
└── 14-线上部署.png
```

按序号命名，博客里插入时顺序清晰。
