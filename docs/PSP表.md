# PSP 表（计划与实际耗时）

> 使用说明：
> 1. **先填「计划时间」列**再开始动手（作业要求：实现前预估）。
> 2. 开发过程中**随手记录**精力/实际开始与结束时间，最后填「实际时间」列。
> 3. 单位是**分钟**，保留整数即可。
> 4. 实际时间与计划时间差异较大是正常的，**博客里要解释差异原因**（这是加分点）。
> 5. 下表数据是根据本项目的真实工作量给的**参考值**，请按你自己的真实情况调整。

## 4. 填写建议

1. **不要编造**。助教看到「计划 1130 分钟、实际 1130 分钟」这种完全一致的数字反而会怀疑。
2. **差异越大越要解释**。差异本身不是扣分项，**不解释**才是。
3. 用记事本或表格**边做边记**，事后回忆很容易失真。
4. 如果某一步真的没做（例如没写单元测试），就如实填 0，不要虚报。
